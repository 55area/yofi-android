# Yo-Fi Landing Page

This workspace will host the promotional site for the Yo-Fi Android app. Landing page development is scheduled after the app is complete. Open `index.html` in a browser to view the starter document.

## Structure

- `index.html` is the HTML entry point.
- `src/` is reserved for CSS and any TypeScript or JavaScript the page needs.
- `public/` is reserved for static assets.

Node.js will run the development and build tools when web work begins. Choose the tooling and scripting language when the landing page scope is defined.

See the [repository README](../README.md), [web instructions](AGENTS.md), and [shared OpenSpec project](../openspec/).
