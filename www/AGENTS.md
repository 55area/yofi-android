# Landing page instructions

Read the [web README](README.md) for the workspace layout. The landing page is scheduled after Android development.

- Keep the HTML entry point, CSS, scripts, assets, and eventual npm package and lockfile under `www/`.
- Use semantic HTML and CSS for the page structure and styling. Add TypeScript or JavaScript where interactions require it.
- Run Node.js tooling from `www/` when it is introduced. Verify page changes in a browser at narrow and wide viewport sizes.
